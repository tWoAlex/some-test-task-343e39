# Некоторое тестовое задание...

## Запуск проекта

1. Перейти в директорию для размещения проекта
2. Клонировать репозиторий:
```
git clone git@github.com:tWoAlex/some-test-task-343e39.git
```
3. Запустить:
```
docker compose -f infra/docker-compose.yaml up -d
```
4. Посетить страницы проекта:
- http://localhost:8000/docs  (Документация)
- http://localhost:15672      (Админка RabbitMQ, логин/пароль `rabbit`/`mq`)

## Особенности реализации:

- Количество абстракций сокращено, зависимости инъектируются с аннотациями конкретных классов
- При запуске приложения захардкодены искусственные задержки для ожидания запуска RabbitMQ (конфигурация `healthcheck` в `docker-compose.yaml` почему-то не дала должного результата)
